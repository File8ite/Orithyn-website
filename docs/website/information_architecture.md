# Purpose

This document defines the structure of the Orythyn website.

It describes:

- Site hierarchy
- Navigation
- User flows
- Content relationships
- Conversion paths

This document serves as the blueprint for UX design and development.

---

# Site Goals

The website should enable visitors to:

- Understand who Orythyn is.
- Understand what Orythyn does.
- Trust Orythyn.
- Contact Orythyn.
- Explore products and services.

# Page Objectives

## Home

Purpose

Introduce Orythyn.

Primary CTA

Book a Discovery Call

---

## About

Purpose

Tell the company's story.

Explain the mission.

Explain the vision.

Explain engineering principles.

Build trust.

Primary CTA

Start a Conversation

---

## Services

Purpose

Explain business outcomes rather than technical features.

Every service should answer:

"What business problem does this solve?"

Primary CTA

Discuss Your Project

---

## Industries

Purpose

Show that Orythyn understands different industries.

Each industry page should explain:

Problems

Solutions

Benefits

---

## Contact

Purpose

Remove friction.

Make contacting Orythyn effortless.

# Exit Points

Services

About

# Mobile Considerations

The mobile experience should prioritize:

Simple navigation

Readable typography

Large touch targets

Fast loading

Minimal scrolling friction

Persistent CTA where appropriate
